# Masri RU — Египетский арабский

Офлайн-курс египетского арабского для русскоговорящих.

## Возможности

- 36 уроков, 12 модулей, диалоги, грамматика и тесты.
- 5 полных программ обучения: A0–B1, разговорная практика, грамматика, чтение/письмо и аудиокурс.
- 702 аудиофайла MP3: 36 уроков, алфавит, фразы и 664 слова; 14 глав учебника в PDF.
- 12 модульных экзаменов и итоговый экзамен; порог 70%, результаты сохраняются.
- Лаборатория письма: 24 задания, проверка набора, алфавит и советы.
- Полный грамматический справочник по всем модулям с поиском и фильтрами.
- Культурный гид: 12 тем о общении, еде, времени, деньгах, здоровье и безопасности.
- Сертификат курса с именем ученика и печатью в PDF после выполнения всех условий.
- Урок «Цвета»: 16 цветов с русскими и арабскими названиями, женские формы, грамматика и фразы (модуль 9).
- Каждое слово курса озвучено отдельным MP3 в разделе «Библиотека → Слова».
- Запись своего голоса и загрузка аудиофайлов (IndexedDB).
- 8 цветовых палитр с названиями на русском и арабском, светлая/тёмная/системная тема.
- Умное повторение, карточки, аудирование, тренажёр глаголов.
- Поиск по урокам, словам, фразам, глаголам, цветам, программам, грамматике, культуре, письму, экзаменам и PDF.
- Резервная копия прогресса и офлайн-режим (PWA).

## Структура аудио

```text
assets/audio/
├── foundations/   alphabet.mp3, survival.mp3
├── lessons/       36 аудиоуроков lesson-m1l1.mp3 … lesson-m12l3.mp3
└── words/         664 слова по модулям m01 … m12
```

Все пути собраны в `word-audio.js` и `textbook-data.js`; библиотека сайта читает их автоматически.

Готовые сценарии для перезаписи уроков и слов своим голосом лежат в `recording/` (см. `recording/README.md`).

## Локальный запуск

Проект использует ES-модули и Service Worker, поэтому его нужно открывать через HTTP-сервер, а не через `file://`.

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы проекта в ветку `main`.
3. В настройках репозитория: **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main` и папку **/(root)**.
5. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` уже добавлен, чтобы GitHub Pages не обрабатывал сайт через Jekyll.

> Для доступа к микрофону нужен HTTPS. GitHub Pages предоставляет HTTPS автоматически.
