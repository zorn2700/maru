# Maru 2.0 — Masri RU

Офлайн-академия египетского арабского для русскоговорящих.

## Что нового в 2.0

- Главная с акцентом на «Продолжить обучение», тренировкой дня, пятью словами, повторением и прогрессом.
- Пошаговый урок из 8 этапов: слово → перевод → транскрипция → аудио → пример → вопрос → речь → тест.
- «Поговори по-египетски»: 40 ситуаций, режим с подсказками и свободный диалог; свои сценарии можно добавить в редакторе контента.
- Умный словарь: поиск по арабскому, русскому, латинице и Arabizi (`3ayez`), избранное, списки, история и фильтр слабых слов.
- Адаптивное повторение (10 минут → 1 → 3 → 7 → 14 → до 30 дней) и четыре отдельные навыка.
- Аудирование на настоящих записях курса: 6 упражнений с вопросами, XP и обновлением дневной цели.
- Дневник слов: слабые слова, избранное, списки, простая и зашифрованная резервная копия (AES-GCM, PBKDF2).
- Тренажёр произношения со сравнением образца и своей записи; проверка распознавания текста не подменяет оценку звука.
- Отчёт о прогрессе с рекомендацией следующего урока и списком слов, требующих повторения.
- **Maru Quest**: карта из 12 миров + финал, звёзды за уроки, экзамены-боссы и разблокировка по прогрессу.
- **Maru Arcade**: три игры на настоящих материалах курса — матч пар, арабский диктант по MP3 и сборка фраз; XP и календарь серии за 35 дней.
- **Галерея достижений**: 26 значков с фильтрами и редкостью; церемония «уровень повышен» с конфетти.
- Обновлённая анимационная подача: сияющий градиент героя, карточки с 3D-наклоном, плавные переходы и поддержка `prefers-reduced-motion`.
- Офлайн: 663 слова теперь можно скачать одной кнопкой, а перемотка аудио/видео работает из кэша (Range-запросы); PWA cache v15.
- Исправлены конфликтующие обработчики резервной копии/сброса и ошибка открытия обычного урока; все импорты копий идут через `BackupEngine`.
- Настройки интерфейса, размера шрифта и приватности; экран готовности офлайн-копии.
- Тесты: `npm run check`, `npm test` (Vitest) и `npm run test:e2e` (Chromium / мобильный Chromium).

> **Источник для публикации — каталог `site/`.** Корневые `app.js`, `styles.css`, `sw.js` и др. остались как историческая копия и не используются при сборке GitHub Pages.
- Полный разбор архитектуры и дорожная карта: [ENGINEERING-REPORT.md](ENGINEERING-REPORT.md).

## Возможности

- 36 уроков, 12 модулей, диалоги, грамматика и тесты. Модули 13–15 из расширенной дорожной карты ещё не добавлены: темы работы частично есть в модуле 10, реалистичные диалоги — в разделе «Диалог», культура — в разделе «Культура».
- 5 полных программ обучения: A0–B1, разговорная практика, грамматика, чтение/письмо и аудиокурс.
- 701 аудиофайл MP3 на диске: 36 уроков, 2 вводных и 663 слова; слово «طازة» пока использует синтез речи. 14 глав учебника в PDF.
- 12 модульных экзаменов и итоговый экзамен; порог 70%, результаты сохраняются.
- Лаборатория письма: 24 задания, проверка набора, алфавит и советы.
- Полный грамматический справочник по всем модулям с поиском и фильтрами.
- Культурный гид: 12 тем о общении, еде, времени, деньгах, здоровье и безопасности.
- Сертификат курса с именем ученика и печатью в PDF после выполнения всех условий.
- Урок «Цвета»: 16 цветов с русскими и арабскими названиями, женские формы, грамматика и фразы (модуль 9).
- Каждое слово курса озвучено отдельным MP3 в разделе «Библиотека → Слова».
- Запись своего голоса и загрузка аудиофайлов (IndexedDB).
- 9 цветовых палитр с названиями на русском и арабском, светлая/тёмная/системная тема.
- Умное повторение, карточки, аудирование на реальных MP3, тренажёр глаголов и произношения.
- Поиск по урокам, словам, фразам, глаголам, цветам, программам, грамматике, культуре, письму, экзаменам и PDF.
- Резервная копия прогресса, зашифрованный экспорт с паролем, редактор сценариев и офлайн-режим (PWA).

## Структура аудио

```text
assets/audio/
├── foundations/   alphabet.mp3, survival.mp3
├── lessons/       36 аудиоуроков lesson-m1l1.mp3 … lesson-m12l3.mp3
└── words/         663 слова по модулям m01 … m12
```

Все пути собраны в `word-audio.js` и `textbook-data.js`; библиотека сайта читает их автоматически.

Готовые сценарии для перезаписи уроков и слов своим голосом лежат в `recording/` (см. `recording/README.md`).

## Локальный запуск

Проект использует ES-модули и Service Worker, поэтому его нужно открывать через HTTP-сервер, а не через `file://`.

```bash
npm run dev
# или: python3 -m http.server 8012 --directory site
```

Откройте `http://localhost:8012/#/home`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы проекта в ветку `main`.
3. В настройках репозитория: **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main` и папку **/site** (именно она является источником публикации).
5. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Файл `.nojekyll` уже добавлен, чтобы GitHub Pages не обрабатывал сайт через Jekyll.

> Для доступа к микрофону нужен HTTPS. GitHub Pages предоставляет HTTPS автоматически.
