# سكريبت التسجيل الصوتي — MASRI RU

هذه الحزمة تحتوي **النص الكامل المنطوق** في ملفات MP3 الخاصة بالدورة، حتى تسجّل الأصوات بصوتك بدل الأصوات الاصطناعية.

- **38 ملفًا صوتيًا للدروس** (الأبجدية وعبارات النجاة و36 درسًا)
- **338 سطرًا منطوقًا**
- **المدة الإجمالية: 13:41**
- **664 ملفًا صوتيًا للكلمات** (640 كلمة فريدة + 24 تكرارًا)
- **حزمة كلمات منفصلة** بملفات TXT وMD وCSV وHTML

> الملفات الصوتية الحالية تحتوي العربية فقط. أسماء المتحدثين والترجمة والترجمة الصوتية موجودة هنا للمراجعة، ولا تُقرأ في التسجيل.

## الملفات

| الملف | الاستخدام |
|---|---|
| `audio-recording-script.html` | النسخة التفاعلية الأنيقة: فهرس، وضع تسجيل، نسخ لكل ملف، طباعة، وتتبّع التقدّم. افتحها في المتصفح. |
| `audio-recording-script.txt` | نص عربي فقط، مناسب للقارئ أو شاشة الهاتف أثناء التسجيل. |
| `audio-recording-script.md` | مرجع كامل بجداول الترجمة والترجمة الصوتية. |
| `audio-recording-script.csv` | بيانات منظّمة (ملف، سطر، متحدث، عربي، ترجمة صوتية، ترجمة) لاستخدامها في أي أداة. |
| `words-recording-script.html` | النسخة التفاعلية لحزمة الكلمات: بحث، فهرس الدروس، وضع تسجيل، نسخ، طباعة، وتتبّع التقدّم. |
| `words-recording-script.txt` | نص الكلمات العربية فقط، مناسب للقارئ أو شاشة الهاتف. |
| `words-recording-script.md` | مرجع كامل للكلمات مع الترجمة النصية والترجمة ومسار كل ملف. |
| `words-recording-script.csv` | بيانات 664 كلمة منظّمة حسب الدرس والوحدة ومسار الملف. |

## حزمة الكلمات

ملفات الحزمة `words-recording-script.*` تغطي كل مفردات الدورة: 664 عنصرًا في 36 درسًا و12 وحدة. كل عنصر له ملف مستقل داخل `assets/audio/words/m01 … m12`.

- اقرأ **العربي فقط** من كل سطر.
- إذا ظهرت «/» فاقرأ الصيغتين معًا، مثل: «روسي / روسية».
- الكلمات المكررة بين الدروس لها ملفات مستقلة، ويمكنك نسخ تسجيل واحد إلى المسارات المكررة بدل إعادة التسجيل (عمود `duplicate_of` في CSV يوضح المسار الأول).
- ملفات الكلمات الحالية مولّدة آليًا، ويمكن استبدال أي ملف بتسجيلك بنفس الاسم والمسار.
- بعد الاستبدال، غيّر رقم الكاش في `sw.js` (حاليًا `masri-ru-v7`) ليقرأ المتصفح النسخ الجديدة.

## طريقة التسجيل

1. افتح `audio-recording-script.html` في المتصفح.
2. اضغط **وضع التسجيل** لإخفاء الترجمة والترجمة الصوتية، أو **إظهار الكل** لمراجعة المعاني.
3. اقرأ الأسطر العربية بالترتيب، بسرعة طبيعية، مع وقفة قصيرة بين كل سطر وآخر.
4. في ملف الأبجدية اقرأ: **اسم الحرف — مثال الحرف**، مثل: «ألف — باب». لا تقرأ الشرطة.
5. اضغط **تم التسجيل** بعد حفظ كل ملف؛ سيبقى تقدّمك محفوظًا في المتصفح.
6. استخدم زر **نسخ النص** إن أردت لصق النص في تطبيق تسجيل أو في ملف نصي.

### إعدادات صوتية مقترحة

- صيغة **MP3**، قناة واحدة (Mono) أو ستيريو، تردد 44.1 kHz.
- صوت واضح بلا موسيقى أو ضوضاء خلفية.
- مستوى ثابت بين كل الملفات.
- لا تضف مقدمة أو خاتمة غير موجودة في النص.

## استبدال الملفات القديمة

ضع تسجيلاتك في المسارات الجديدة:

```text
assets/audio/foundations/   alphabet.mp3، survival.mp3
assets/audio/lessons/       lesson-m1l1.mp3 … lesson-m12l3.mp3
assets/audio/words/m01 … m12/   ملفات الكلمات
```

بنفس أسماء الملفات الحالية:

```text
alphabet.mp3
survival.mp3
lesson-m1l1.mp3 … lesson-m12l3.mp3
m1l1-01-ahlan.mp3 … (ملفات الكلمات)
```

المسار `lesson-m<الوحدة>l<الدرس>.mp3`، مثل `lesson-m3l2.mp3` للوحدة 3 والدرس 2. لا تغيّر الأسماء ولا الامتداد حتى تعمل الصفحة دون تعديل الكود.

> **مهم:** خدمة PWA تخزّن الملفات الصوتية مؤقتًا. بعد استبدال التسجيلات، غيّر رقم الكاش في `sw.js` من `masri-ru-v7` إلى رقم أحدث، ثم أعد تحميل الصفحة لسماع النسخة الجديدة.

### التحقق من المدة

```bash
for f in assets/audio/foundations/*.mp3 assets/audio/lessons/*.mp3; do
  printf '%s  ' "$f"
  ffprobe -v error -show_entries format=duration -of default=nw=1:nk=1 "$f"
done
```

## ملاحظات

- ملفات MP3 الحالية قصيرة (نحو 15–30 ثانية للدرس)، لذلك يمكن إعادة تسجيلها ملفًا واحدًا في كل جلسة.
- السكريبت مبني مباشرة من بيانات الموقع (`course-data.js` و`textbook-data.js`)، لذا فإن ترتيب الأسطر مطابق للمحتوى المعروض.
- إذا عدّلت نصًا في الموقع لاحقًا، حدّث السكريبت يدويًا أو أعد توليده من البيانات.
