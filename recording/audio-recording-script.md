# Текст всех MP3 для озвучки

Полный сценарий 38 аудиофайлов курса: **338 строк**, общая длительность **13:41**.

> Читайте только арабский текст. Имена говорящих, транскрипция и перевод — подсказки для записи, их не нужно произносить.

## Как записывать

1. Откройте трек, включите диктофон и прочитайте арабские строки по порядку.
2. Держите естественный темп и делайте короткую паузу между репликами.
3. В алфавите читайте имя буквы, затем пример: **ألف — باب**. Тире не читается.
4. Сохраняйте имя файла и формат MP3. Тогда запись можно положить в `assets/audio/` вместо старой версии: `foundations/` для алфавита и фраз, `lessons/` для уроков.
5. Для быстрой записи используйте `audio-recording-script.txt` — там только арабский текст без переводов.
